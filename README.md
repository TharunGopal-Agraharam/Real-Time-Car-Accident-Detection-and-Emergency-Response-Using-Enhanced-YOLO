**🚗 Real-Time Car Accident Detection & Emergency Response using Enhanced YOLO**

🔹**Overview**
A real-time car accident detection system using an enhanced YOLO model, capable of detecting collisions instantly and triggering emergency alerts to minimize response time.

⚡ **Features**
-Real-Time Detection: Detect accidents from live video streams or dashcams.
-Enhanced YOLO: Optimized model for high accuracy and speed.
-Emergency Alerts: Notifies emergency services or contacts with location.
-Data Logging: Stores incidents for future analysis.
-User-Friendly Interface: Monitor live feeds easily.
